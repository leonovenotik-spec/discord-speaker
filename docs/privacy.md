# Обработка данных

Discord Speaker озвучивает текст в голосовых каналах Discord. Этот документ описывает
поведение кода из данного репозитория и публичного бота, на которого ведёт приглашение
в README. У самостоятельно размещённых копий могут быть другие владельцы и настройки.

## Текст и аудио

Текст из команды, формы или назначенного канала передаётся Microsoft Edge TTS
для синтеза речи. Полученный аудиофайл временно хранится во время обработки и удаляется
после неё. Текст сообщений не записывается в журнал и не сохраняется в базе бота.
Ожидающие сообщения находятся в памяти до обработки, очистки очереди или остановки процесса.

Бот обрабатывает новые сообщения только в канале, выбранном управляющим сервером.
История сообщений не загружается. Бот подключается к голосовому каналу с отключённым
приёмом звука, не слушает и не записывает разговоры.

## Сохраняемые настройки

На диске сохраняются:

- ID сервера, выбранной роли доступа и текстового канала озвучки;
- ID участников, их выбранные голоса и скорости;
- ID сервера и участника в записи для восстановления временного серверного мута.

Запись восстановления удаляется после успешного снятия мута. Настройки сохраняются
между перезапусками. Автоматическое удаление всех настроек при выходе бота с сервера
сейчас не реализовано. Технический журнал содержит сведения о запуске, ошибках,
подключениях и времени подготовки речи; он может включать ID серверов и каналов.

## Сторонние сервисы и обращения

Сообщения и взаимодействия также обрабатываются Discord, а синтез — сервисом Microsoft.
К этим сервисам применяются их собственные условия обработки данных.

Вопросы об обработке или удалении настроек публичного бота можно направить через
[Issues](https://github.com/leonovenotik-spec/discord-speaker/issues).
Не публикуйте в обращении секреты или содержимое личных сообщений.
Для самостоятельной копии обращаться следует к её владельцу.
