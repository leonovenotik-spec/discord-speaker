# Озвучка в Discord с телефона

Это бот для голосового канала сервера. Отдельную APK устанавливать не нужно.
Ты управляешь ботом из Discord на Android, а сам бот постоянно работает на хостинге.
Бот работает на всех серверах, куда его добавили. По умолчанию пользоваться им могут
все участники. Управляющий сервером может ограничить доступ выбранной ролью через `/access`.

## Что он делает

Для телефона удобнее ввести `/panel`: появится личная панель, видимая только тебе.
Выбери голос и скорость, нажми **«Озвучить»**, введи фразу и отправь её.
Кнопка **«Стоп»** останавливает речь. Панель действует 15 минут; после истечения
срока или перезапуска бота снова введи `/panel`.

Выбранные голос и скорость сохраняются на постоянном диске хостинга и восстанавливаются
после перезапуска отдельно для каждого участника на каждом сервере. Текст фраз не сохраняется.

Если удобнее команда, по-прежнему можно использовать `/say`:

1. Войди в обычный голосовой канал сервера.
2. В текстовом канале введи `/say`, выбери поле `text` и напиши фразу.
3. По желанию выбери голос в поле `voice`: Дмитрий, Светлана, Эндрю, Брайан, Ава или Эмма.
4. Бот подготовит речь, подключится к твоему каналу, поставит тебе серверный мут,
   озвучит фразу и снимет поставленный им мут. Между фразами бот остаётся в канале.
   Он выйдет, когда уйдёт первый вызвавший участник или не останется людей; также есть `/leave`.

Звук идёт от имени бота. Во время подготовки речи микрофон ещё не отключён.
Если ты заранее выключил свой микрофон кнопкой Discord, эта кнопка останется выключенной.
Если серверный мут уже был включён до команды, бот не станет говорить или снимать его.
Длина текста — до 500 символов. `/stop` отменяет подготовку или останавливает речь.
Трибуны (Stage) не поддерживаются.

## Выбор голоса

В команде `/say` заполни `text`, а затем необязательные поля `voice` и `speed`.
Указанные голос и скорость запоминаются. Без выбора используются последние настройки;
при первом запуске — Дмитрий и обычная скорость. В панели тоже можно менять эти настройки.
Доступны пять скоростей: медленно, чуть медленнее, обычно, чуть быстрее и быстро.

| Голос в меню | Тип |
| --- | --- |
| Дмитрий | Мужской, русский |
| Светлана | Женский, русский |
| Эндрю | Мужской, многоязычный |
| Брайан | Мужской, многоязычный |
| Ава | Женский, многоязычный |
| Эмма | Женский, многоязычный |

Многоязычные голоса тоже поддерживают русскую речь; произношение и акцент могут отличаться.
Язык определяется по тексту. Это отдельные голоса, а не изменение высоты одного голоса.
Сведения Microsoft о языках: https://learn.microsoft.com/en-us/azure/ai-services/speech-service/speech-synthesis-markup-voice

Если бот уже размещён, обнови репозиторий целиком и дождись повторного запуска
хостинга: список голосов обновится при регистрации команды.

## 1. Создать бота с телефона

Открой https://discord.com/developers/applications в браузере.
При необходимости включи «Версия для ПК» в меню браузера.

1. Нажми **New Application**, введи имя, например «Мой голос».
2. Открой приложение, затем раздел **Bot**.
3. Нажми **Reset Token**, подтверди действие и скопируй токен.
   Это секретный ключ именно бота. Его нужно вставить только в настройки хостинга.
   Не отправляй его в чат, не публикуй в GitHub. При утечке снова нажми Reset Token.
4. Открой **Installation** («Установка»), включи **Guild Install** («Установка гильдиями»).
5. Для Guild Install выбери scopes **bot** и **applications.commands**.
6. Выбери права **View Channels**, **Connect**, **Speak**, **Mute Members**.
7. Открой **Install Link**, выбери свой сервер и подтверди добавление.

Для `/say` и `/panel` привилегированные intents не нужны. Для озвучки обычных сообщений
включи **Message Content Intent** в разделе **Bot → Privileged Gateway Intents**.
Бот проверит разрешение при следующем запуске.
В настройках конкретного голосового канала тоже должны быть разрешены перечисленные права.

Официальная инструкция Discord:
https://discord.com/developers/quick-start/getting-started

## 2. Настроить доступ после запуска

ID сервера и режим разработчика не нужны. По умолчанию озвучка доступна всем.
После запуска управляющий сервером может выполнить `/access role:…`, выбрав роль в Discord.
`/access everyone:True` снова открывает доступ всем; `/access` показывает текущую настройку.
Управляющие сервером могут пользоваться ботом независимо от выбранной роли.

Для автоозвучки обычных сообщений после запуска выбери `/textchannel channel:…`.
Участники должны находиться в голосовом канале; сообщения поступят в очередь.
`/textchannel disable:True` отключает этот режим. Подробнее — в [README](../README.md).

## 3. Запустить на хостинге с телефона

Один из вариантов — Railway: https://railway.com . Это отдельный сервис,
для непрерывной работы могут понадобиться платный тариф и способ оплаты.
Проверь текущие условия перед запуском. Компьютер для этих шагов не нужен.

1. В Railway войди со своим аккаунтом GitHub и создай проект → **Deploy from GitHub repo**.
   Выбери репозиторий `leonovenotik-spec/discord-speaker`. Если используешь свою копию,
   выбери её; файлы бота должны находиться в корне репозитория.
2. В **Variables** сервиса добавь:

   | Имя | Значение |
   | --- | --- |
   | `DISCORD_TOKEN` | Секретный токен из раздела Bot |
   | `DATA_DIR` | `/app/data` |

3. Добавь постоянный **Volume** и укажи путь подключения `/app/data`.
   Здесь хранятся запись для восстановления микрофона после сбоя и настройки голоса и скорости.
4. Примени изменения и нажми **Deploy**. Оставь одну реплику сервиса.
   Это постоянно работающий бот; публичный домен и HTTP-порт ему не нужны.
   Режим засыпания сервиса должен быть выключен.
5. Дождись записи **READY** в журнале запуска. В Discord появятся `/panel`, `/say`, `/stop`, `/restore`, `/access`, `/leave`, `/textchannel`.

Не добавляй токен в файлы репозитория. В проекте есть только пример `.env.example` без секретов.

Railway: запуск из GitHub — https://docs.railway.com/quick-start
Переменные — https://docs.railway.com/variables
Постоянный диск — https://docs.railway.com/volumes

## Если что-то пошло не так

- **Нет команды /say:** проверь установку приложения на сервер,
  scope applications.commands и запись READY в журнале; перезапусти Discord.
- **Нет звука:** проверь права Connect/Speak и то, что бот не заглушён на сервере.
- **Остался серверный мут после сбоя:** войди в голосовой канал и введи `/restore`.
  При сохранённом Volume бот также пытается восстановить микрофон после перезапуска
  и при твоём возвращении в канал. Если бот недоступен, сними серверный мут вручную
  через меню своего участника. Автоматическое восстановление при отключённом хостинге невозможно.
- **Ошибка озвучки:** нужен доступ хостинга к интернету и сервису синтеза речи.
- **Твой микрофон по-прежнему выключен после успешной озвучки:** проверь собственную
  кнопку микрофона. Бот меняет серверный мут, а не твою личную кнопку.

Во время работы бота не меняй серверный мут вручную: Discord не различает, кто
повторно включил тот же самый мут; завершение озвучки снимает мут, поставленный ботом.

## Текст и проверка

Текст передаётся онлайн-сервису Microsoft Edge TTS для синтеза. В журнал бота текст
и токен не записываются. Временный звуковой файл удаляется после обработки команды.
Бот не слушает и не записывает разговор в голосовом канале.

Проверены регистрация команд, восстановление микрофона, сохранение настроек,
выбранные пункты панели, отправка формы, настройка роли и независимость серверов.
Проверки микрофона включают ошибку воспроизведения, уже включённый серверный мут и перезапуск. Также выполнен
реальный синтез русской фразы всеми шестью голосами и проверено преобразование
каждого результата в голосовой формат Opus.
Дополнительно проверен реальный синтез на медленной и быстрой скоростях.
Подключение к твоему серверу не выполнено:
для проверки реального голоса и прав нужны созданный тобой бот и развёртывание на хостинге.
