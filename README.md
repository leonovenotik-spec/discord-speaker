Пишите сообщения в выделенный текстовый канал — бот прочитает их участникам голосового
канала. Для отдельных фраз есть команда `/say` и личная панель `/panel` с выбором голоса
и скорости. Всё управление доступно в Discord на компьютере и телефоне.

## Начало работы

1. [Добавьте бота на сервер](https://discord.com/oauth2/authorize?client_id=1561162956358549504&scope=bot%20applications.commands&permissions=7408640&integration_type=0).
   Для установки нужно право **«Управлять сервером»**.
2. Зайдите в обычный голосовой канал и откройте `/panel`.
3. Выберите голос, нажмите **«Озвучить»** и отправьте текст. Можно сразу использовать
   `/say text:Привет!`.

Для автоматической озвучки управляющий сервером назначает текстовый канал:
`/textchannel channel:#озвучка`. После этого все участники **того же голосового канала,
где находится бот**, могут писать туда обычные сообщения. Первая фраза запускает сеанс.
Создавать собственное приложение, получать токен и настраивать хостинг для этого не нужно.

## Возможности

- Шесть голосов и пять скоростей речи. Выбор сохраняется для каждого участника отдельно.
- Фразы до 500 символов; очередь до 20 ожидающих сообщений из текстового канала.
- Личная панель с выбором голоса, вводом текста и остановкой речи.
- Временный серверный мут автора фразы и восстановление микрофона после озвучки.
- Доступ для всех по умолчанию; при необходимости — ограничение по роли.
- Независимые настройки и одновременная работа на разных серверах.

Бот остаётся в голосовом канале между фразами. Он выходит, когда вызвавший его участник
покидает или меняет канал, когда в канале не остаётся людей, либо по команде `/leave`.
Другие участники могут пользоваться озвучкой, не меняя владельца сеанса.

## Команды

| Команда | Назначение |
| --- | --- |
| `/panel` | Личная панель: голос, скорость, ввод текста и остановка |
| `/say text:…` | Озвучить фразу; поля `voice` и `speed` меняют личные настройки |
| `/stop` | Остановить свою фразу; управляющий сервером может остановить любую |
| `/restore` | Снять серверный мут, оставшийся после сбоя озвучки |
| `/leave` | Завершить сеанс и очистить очередь; для вызвавшего бота или управляющего |
| `/textchannel channel:…` | Назначить текстовый канал для автоозвучки |
| `/textchannel disable:True` | Выключить автоозвучку |
| `/access role:…` | Разрешить озвучку выбранной роли |
| `/access everyone:True` | Открыть доступ всем участникам |

`/access` и `/textchannel` без параметров показывают текущие настройки.
Менять их могут владелец сервера и участники с правом **«Управлять сервером»**.
Управляющие сохраняют доступ к озвучке при включённом ограничении по роли.
Панель действует 15 минут; новую можно открыть командой `/panel`.

## Голоса

| Голос | Тип |
| --- | --- |
| Дмитрий | Мужской, русский |
| Светлана | Женский, русский |
| Эндрю | Мужской, многоязычный |
| Брайан | Мужской, многоязычный |
| Ава | Женский, многоязычный |
| Эмма | Женский, многоязычный |

Многоязычные голоса поддерживают русский; произношение может отличаться.
Скорости: медленно, чуть медленнее, обычно, чуть быстрее и быстро.
По умолчанию используются Дмитрий и обычная скорость.

## Права и поведение

При добавлении бот запрашивает просмотр каналов, отправку сообщений, чтение истории
сообщений, подключение к голосовым каналам, речь и отключение микрофона участников.
Отправка сообщений и доступ к истории нужны для ответов с пояснениями в канале озвучки.
Права должны быть разрешены и в настройках выбранных каналов.

Во время подготовки речи микрофон автора остаётся включённым. Во время воспроизведения
бот ставит серверный мут и затем снимает его. Личную кнопку микрофона Discord он
не переключает. Если на участнике уже стоит серверный мут, озвучка не запускается.
Трибуны не поддерживаются.

Автоозвучка обрабатывает только новые сообщения из назначенного канала. История,
сообщения ботов, вебхуки и вложения не озвучиваются. При выходе из голосового канала
или переходе в другой ожидающая фраза пропускается. Завершение сеанса очищает очередь.

## Если что-то не работает

- **Нет команд:** убедитесь, что бот добавлен на сервер, и перезапустите Discord.
- **Сообщение не озвучивается:** проверьте выбранный текстовый канал, роль доступа
  и то, что автор находится в голосовом канале бота.
- **Нет звука:** проверьте права бота подключаться и говорить, а также серверный мут бота.
- **После сбоя остался мут:** зайдите в голосовой канал и выполните `/restore`.
  Если бот недоступен, управляющий сервером может снять серверный мут вручную.

Речь синтезируется внешним сервисом, поэтому время подготовки зависит от его работы.
При сообщении об ошибке укажите команду и поведение бота в
[Issues](https://github.com/leonovenotik-spec/discord-speaker/issues). Не публикуйте токены
и личный текст сообщений.

## Данные

Текст передаётся Microsoft Edge TTS для синтеза речи. Бот не записывает разговоры,
не сохраняет тексты сообщений и удаляет временный аудиофайл после обработки.
На диске остаются настройки серверов и участников, а также записи для восстановления
микрофона после сбоя. Подробнее — [обработка данных](docs/privacy.md).

## Самостоятельный запуск и разработка

Исходный код доступен для запуска собственного экземпляра:

- [Настройка приложения, Docker и локальный запуск](docs/setup.md)
- [Установка сервиса на Linux](docs/linux-server.md)

Требуются Python 3.12+ и зависимости из `requirements.txt`. FFmpeg поставляется через
`imageio-ffmpeg`. Проверки не требуют токена и не подключаются к Discord:

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

CI выполняет проверки на Python 3.12 и 3.14.
